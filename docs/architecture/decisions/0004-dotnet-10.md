# 0004 — Migrar de .NET 8 para .NET 10

**Data:** 2026-10-16
**Status:** Aceito
**Fase:** 00-roteiro-portfolio (executada na 01)

## Contexto

Os dois serviços usam `net8.0`. O suporte do .NET 8 termina em **2026-11-10**; o .NET 10 é a versão LTS atual. A máquina de desenvolvimento só tem o SDK 10 instalado. Um projeto de portfólio numa versão fora de suporte passa impressão de abandono.

## Decisão

Atualizar `TargetFramework` para `net10.0` nos dois serviços na Fase 01, junto com os pacotes `Microsoft.*`/EF Core/Npgsql para as versões compatíveis com .NET 10.

## Alternativas consideradas

- **Ficar no .NET 8** — menos trabalho agora, mas fora de suporte em menos de um mês.

## Consequências

- Imagens base `mcr.microsoft.com/dotnet/aspnet:10.0` e `sdk:10.0` na Fase 05; CI com `dotnet-version: 10.0.x`.
- Pacotes atualizados juntos; quebras de API (ex.: Swashbuckle × OpenAPI nativo) são resolvidas no brainstorming da Fase 01.
